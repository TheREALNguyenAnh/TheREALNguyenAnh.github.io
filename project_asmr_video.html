Overview

This project focused on building an end-to-end automated content generation pipeline tailored for creating ASMR short videos. By integrating various AI models and scripting tools, I developed a system capable of streamlining the entire video creation process, from ideation to final render.

Technical Implementation

  • Developed a content generation pipeline using Python, Ollama, and Google AI Studio
  • Automated the creation of ASMR short videos, significantly reducing manual production time
  • Implemented intelligent prompt generation to create diverse and engaging video concepts
  • Engineered an automated video downloading and processing system to handle assets locally

Key Achievements

  • Successfully deployed the automated content to new YouTube channels
  • Achieved strong initial traction, with generated ASMR shorts averaging 2K views per video
  • Demonstrated practical application of LLMs (Ollama, Google AI) in creative content automation
